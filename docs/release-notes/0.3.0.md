# mur-voir 0.3.0

This release reads the 900 MHz radio directly and brings the dashboard up to the mur-msgs v1.0.0 DBCs.

## Connect over 900 MHz

Plug the base XBee radio into USB, open **File > Connect** (Cmd/Ctrl+K), choose **900 MHz radio** and click Connect. There is no address to enter, and the Wireless-telem base station and radio bridge are not needed.

- The desktop app finds the radio's USB adapter (FTDI or Silicon Labs) without asking.
- Hosted Lite works in Chrome and Edge. The browser asks you to pick the radio the first time. Safari and Firefox cannot open USB serial ports.
- The radio must be in API mode (AP=1 or AP=2) at 9600 baud, as Wireless-telem configures it. Close XCTU and the base station first, because only one program can hold the port.
- The connection status shows the radio's address and the packet count. If no car packets arrive, the car's `XBEE_DESTINATION` must be the address shown.
- CAN frames decode with the bundled DBCs into the same `<NODE>/<Signal>` fields as candump and MQTT raw CAN, so saved layouts work. LV battery values appear under their own names.
- Car timestamps more than 10 seconds from the laptop clock fall back to receive time and show the approximate-time indicator.
- If the radio is unplugged, the dashboard keeps the received data and reconnects when it is plugged back in.

The radio carries the Shakedown selection in Wireless-telem's `[[live]]` list at 1 to 3 Hz, not every channel.

## Other changes

- Bundled DBCs move to mur-msgs v1.0.0, which multiplexes the ENNOID cell voltages. Old flat snapshots still decode (#24, #28).
- File > Download runs browses and opens runs from the MUR archive, with incomplete and inferred run ends marked (#21, #22).
- File > Add Track Day Layout adds the bundled nine-tab track day layout. Lite opens it the first time (#20).
- The sidebar filter matches field names by words in any order and can show only live fields (#19).
- Live fault bits show their DBC names and severity (#23).
- Desktop installers are uploaded only for tagged releases and manual runs (#27).

## Downloads

Desktop installers are available for macOS and Windows on x64 and arm64, with AppImages for Linux x64 and arm64. The Lite ZIP runs through its included Node server and needs no npm installation. SHA256SUMS.txt contains archive checksums.

The desktop builds have no developer signing certificate or notarisation. Operating systems may ask you to approve the downloaded app. Keep original telemetry logs.

## Verification limits

The radio source was checked against the car on the bench through a real base radio: the headless desktop app connected three times out of three and decoded 94 fields. Its tests replay six seconds recorded from that radio. Hosted Lite in Chrome, Windows and Linux serial drivers, and radio range on track have not been tested.
