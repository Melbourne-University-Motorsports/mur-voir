# mur-voir 0.3.1

The 900 MHz radio source now reads Wireless-telem's faster radio format and finds the radio's serial speed by itself.

## Changes

- The radio source decodes version 2 radio packets as well as version 1. Version 2 is the compact format Wireless-telem uses to send every CAN frame at up to 20 Hz, and the driver channels at 50 Hz.
- Connecting tries 230400 baud, then 9600, then the other standard XBee speeds, and uses the first one the radio answers. There is still nothing to set: plug in the radio and choose **900 MHz radio** in File > Connect.

## Downloads

Desktop installers are available for macOS and Windows on x64 and arm64, with AppImages for Linux x64 and arm64. The Lite ZIP runs through its included Node server and needs no npm installation. SHA256SUMS.txt contains archive checksums.

The desktop builds have no developer signing certificate or notarisation. Operating systems may ask you to approve the downloaded app.

## Verification limits

The version 2 decoder is tested against Wireless-telem's own test vector and a hand-built packet. Baud detection was checked against the base radio at 9600 baud. A live version 2 stream from the car at 230400 baud waits for the radio change.
