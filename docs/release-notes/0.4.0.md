# mur-voir 0.4.0

The dashboard now uses a fraction of the energy it did while live, connects to the team backend by default, and names each node's fault bits.

## Less energy while live

Earlier versions redrew every tab, visible or not, 60 times a second. This release draws only when something on screen changed. Measured against the car over cellular, as a percentage of one CPU core for the whole app:

| Tab                                  | 0.3.1 | 0.4.0 |
| ------------------------------------ | ----: | ----: |
| Track day                            |   74% |   10% |
| HV voltage                           |   41% |   19% |
| Motor and torque                     |   43% |   16% |
| Pedals                               |   37% |   12% |
| Track day with a Trackside satellite |   93% |   14% |

- While live, graphs on a session-time axis scroll at up to 20 frames per second, even when data pauses. Other tabs redraw only when their data changes, and field values next to the graph update 10 times per second.
- Tabs you are not looking at stop streaming. When you open one again, it fetches the history it missed.
- A Trackside satellite receives only the tiles that changed, and stays with the hub window that opened it, also after a restart.

## Connect

- **File > Connect** now offers `http://mur-base:8080`, the team backend on the MUR tailnet, for MUR Telemetry. Enter `http://localhost:8090` to use the mock backend. Lite still connects to the server it was opened from.

## Graphs and faults

- A signal that keeps sending the same value, such as a pedal at zero in Standby, draws as a held line up to the live edge instead of a gap. Gaps start after at least 2 seconds without data, so the cellular link's 1-second refresh of steady values no longer reads as missing data.
- `MUR_Fault` bits have names for each node, from the mur-msgs v2.0.0 DBCs.
- Integrate and Differentiate now show correct values where a trace has a gap.
- A field placed in two Trackside tiles on one tab raises its limit alert once.
- A graph whose fields have no numeric samples says so after they finish loading, instead of staying blank.

## Lite

- Lite opens the Track Day layout on first visit, even when its assets load slowly.
- The hosted Lite server closes connections that a browser abandons mid-handshake, so it no longer leaks memory.

## Downloads

Desktop installers are available for macOS and Windows on x64 and arm64, with AppImages for Linux x64 and arm64. The Lite ZIP runs through its included Node server and needs no npm installation. SHA256SUMS.txt contains archive checksums.

The desktop builds have no developer signing certificate or notarisation. Operating systems may ask you to approve the downloaded app.

## Verification limits

The energy figures are medians from paired runs with the car in Standby on cellular, not while driving. The 0.3.1 column was measured on the main branch just before this release's performance changes, which renders the same way as 0.3.1. Live data still arrives in bursts, from the cellular link and from the tailnet relay between some laptops and the backend. Graphs now scroll smoothly through those pauses, but this release does not remove them.
