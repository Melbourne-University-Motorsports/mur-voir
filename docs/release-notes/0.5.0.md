# mur-voir 0.5.0

A new Cells tab shows every accumulator cell voltage at once, live or at the cursor in a log.

## Cells tab

The ENNOID BMS reports 108 cells. The Cells tab draws one bar per cell in two rows of 54, with a gap after every 18-cell segment. Each bar is labelled with its cell number and voltage, and hovering a bar shows its distance from the pack mean and its field name.

- Bars outside the tab's low and high limits draw red. A bar more than the outlier distance from the pack mean draws amber. A cell that stopped updating draws grey and shows its age when you hover it.
- A header gives the lowest and highest cell, the spread and the mean.
- The axis fits the current values but never zooms in below 200 mV, so a healthy pack doesn't look uneven. The lock button holds the current range.
- `ENNOID_CellVoltageMin` and `ENNOID_CellVoltageMax` draw as reference lines. They are logged 9 times a second and catch peaks the 1 Hz cell burst misses.
- A Temperatures view takes temperature fields with their own limits. It stays empty until the BMS has temperature sensors configured.

The Track Day layout has a Cells tab with all 108 cells, limits of 2.5 V and 4.2 V (the TTCS trip limits), a 150 mV outlier distance and both reference lines. Lite opens with the Track Day layout only in a browser with no saved layout. In a browser that already has one, File > Add Track Day Layout adds the Cells tab along with a second copy of the other layout tabs.

In logs, a cell counts as stale when its last sample is more than 3 seconds before the cursor. Log imports now keep every ENNOID cell sample, including repeated values, so a cell holding a steady voltage isn't marked stale.

## Layout link

`?layout=default` in Lite added the Track Day layout a second time when a tab in it kept its default title. It now recognises the layout as open.

## Downloads

Desktop installers are available for macOS and Windows on x64 and arm64, with AppImages for Linux x64 and arm64. The Lite ZIP runs through its included Node server and needs no npm installation. SHA256SUMS.txt contains archive checksums.

The desktop builds have no developer signing certificate or notarisation. Operating systems may ask you to approve the downloaded app.
